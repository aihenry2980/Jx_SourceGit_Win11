fork notice

这是对原始 SourceGit 项目的个人 fork

本工具基于原始开源项目 sourcegit-scm/sourcegit。 原始作品的核心设计、版权和贡献归原作者及贡献者所有。本 fork 不是 upstream 官方发行版， 主要用于加入我自己的 Windows 仓库维护、分支筛选、history graph 和递归 submodule 工作流增强。

feature ledger from commit history

从 commit message 整理出来的增强清单

下面这些点来自本 fork 相对 upstream 的提交记录，按日常使用场景归类。它不是空泛的 feature wall， 更像一张维修台上的改装记录。

01 / SUBMODULE BAY

递归 submodule 和 SPP 工作流

  • 递归 submodule update 的顺序、弹窗、结果报告和状态 UX 做了多轮打磨。
  • 递归 local changes view、递归 clean action、nested file details 更适合维护大型嵌套仓库。
  • submodule diff summary 更清楚，丢失 revision 时禁用 Open Details，减少误点。
  • 围绕 super-project pointer 做过滤、标记和图谱提示，便于追踪 submodule 指针变化。
  • AvaloniaEdit submodule 保持使用个人 fork，并吸收 upstream 需要的变更。
02 / HISTORY CORE

History graph、refs 和拖拽操作

  • 改进 history graph change indicators、graph markers、commit summary 和 graph alignment。
  • 增强 refs/tag 显示、bookmark 颜色、history tag toggle 和小屏幕可用性。
  • commit subject 和 refs 支持拖拽动作，带 Rebase / Hard Reset 的指针反馈和取消清理。
  • 支持 Ctrl + wheel 缩放 history 窗口，历史空状态信息更明确。
  • 关闭 debug instance 时对 graph generation 加保护，避免 UIStates 为空导致异常。
03 / BRANCH FILTER

分支过滤、颜色和上下文菜单

  • Preset Branch Filter 支持 exact names、contains patterns、exclude names。
  • 修复 contains pattern 自动补全问题，并修复 exact names chip 在输入框中被截断的问题。
  • 跨 repo 对比 matching remotes，远程分支 context menu 更易读。
  • 分支 context menu 增加更快的颜色和 push 操作路径。
  • Push 流程里的 remote branch 自动选择和 branch selector 更适合多远程仓库。
04 / FETCH PIPE

Fetch、LFS 和命令流程反馈

  • Quick fetch modes、dark toolbar theme 和 fetch feedback 有单独增强。
  • 修复 LFS 场景可能卡住的问题，并收紧 auto-fetch state handling。
  • 命令工作流、递归操作、Actions popup 行为和 countdown 反馈更直观。
  • 窄窗口下减少 toolbar 按钮宽度和间距，避免工具栏图标互相挤压。
  • 增加 remote git address text，查看仓库来源更直接。
05 / DIFF WORKBENCH

Diff、local changes 和冲突处理

  • submodule diff summaries 和 nested file details 帮助理解指针与文件层级变化。
  • local changes layout、diff 交互和 branch filter 交互做了 polish。
  • 支持配置 pull-related conflicts 时自动 revert 的文件扩展名。
  • 保留 SourceGit 的 text diff、stash、rebase、worktree 基础能力，同时针对本 fork 工作流补强。
  • 局部修复和防错逻辑减少误操作后的状态不一致。
06 / WINDOWS RIG

Windows 发布、诊断和启动器

  • 增加 Windows self-update install workflow 和 release cmd script。
  • release workflow 限制到 Windows x64，减少不需要的平台产物。
  • 增加 memory profiling window，用来定位打开的仓库和 UI 功能的内存占用。
  • Launcher title bar、+Folder shortcut 和仓库侧栏布局更贴近日常启动流程。
  • 增加“do not close window”方向的窗口保护尝试，以及更多小型按钮和操作入口。
