A customized fork of SourceGit

Jx SourceGit Win11

一个面向日常开发工作流定制的 Git GUI：保留 SourceGit 的快速、清晰和跨平台基础， 并加入预设分支过滤、分支颜色、高亮和递归 submodule 工作流等增强。

Fork notice

这是对原始 SourceGit 项目的 fork

本工具基于原始开源项目 sourcegit-scm/sourcegit。 原始作品的核心设计、版权和贡献归原作者及贡献者所有。本 fork 不是 upstream 官方发行版， 主要用于加入我自己的 Windows/日常仓库管理工作流增强。

Why this fork

给复杂分支和 submodule 仓库多一点秩序

预设分支过滤

用 exact names、contains patterns 和 exclude names 控制左侧分支树，常用分支一键回到可读状态。

图谱高亮和颜色

为 exact-match 分支保存颜色，增强 HEAD、SPP 和选中提交在 commit graph 里的视觉反馈。

递归 submodule 工作流

围绕 super-project pointer、递归更新、递归清理和 submodule diff 做了更贴近日常维护的增强。

保留 SourceGit 基础体验

继续使用 SourceGit 的快速启动、清晰历史图、diff、stash、rebase、worktree 和跨平台基础能力。
